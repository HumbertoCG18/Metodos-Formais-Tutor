## Referências importadas

### GitHub - Consensys/eth2.0-dafny: Eth2.0 spec in Dafny · GitHub
- **URL:** https://github.com/ConsenSys/eth2.0-dafny
- **Tags:** main
- **Resumo:** Este repositório apresenta uma especificação formal do protocolo Ethereum 2.0 utilizando Dafny, uma linguagem de programação com suporte nativo à verificação de software. O projeto busca mitigar bugs e vulnerabilidades de segurança na Beacon Chain por meio de provas matemáticas e lógica de Hoare, garantindo que a implementação siga rigorosamente a especificação técnica. Como recurso educacional, a referência serve de apoio para o estudo de sistemas distribuídos seguros, permitindo que alunos compreendam transições de estado complexas e utilizem especificações formais para gerar códigos verificados em linguagens como Go e C#.
- **Relevante para:** unidade-01-metodos-formais / linguagens de especificacao e logicas, fundamentos de logica de primeira ordem, abordagens para verificacao formal · unidade-02-verificacao-de-programas / logica de hoare, sistema de prova, softwares de suporte a verificacao formal de programas
- **Incluir no bundle:** sim

### GitHub - aws/aws-encryption-sdk: AWS Encryption SDK · GitHub
- **URL:** https://github.com/aws/aws-encryption-sdk
- **Tags:** main
- **Resumo:** Este repositório apresenta a implementação em Dafny do AWS Encryption SDK, projetado para realizar criptografia segura de dados diretamente no lado do cliente. Ele demonstra a aplicação prática de criptografia de envelope, na qual cada objeto de dados é protegido por uma chave de dados exclusiva, que por sua vez é encapsulada por uma chave mestre. O recurso é valioso para estudantes explorarem conceitos de segurança e verificação formal de código. Além disso, apoia o aprendizado sobre geração de código a partir de modelos Smithy e a transpilação do SDK compilado para runtimes como .NET e Rust.
- **Incluir no bundle:** sim
